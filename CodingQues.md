1. Arrays & Strings

Find the largest sum contiguous subarray (Kadane's Algorithm)

    Problem: Find the maximum sum of a subarray of size k in a given array.

    Variants: Find the maximum subarray sum without using extra space, using sliding window technique.

Find the missing number in an array of consecutive numbers

    Problem: Given an array of n-1 integers in the range [1, n], find the missing number.

    Algorithm: Use the sum formula or XOR trick.

Reverse a string or an array in place

    Problem: Reverse a string in place, without using extra memory.

    Follow-up: Reverse words in a string.

Find all pairs in an array that sum to a given target

    Problem: Find two numbers in the array that sum up to a given target.

    Follow-up: Find all unique pairs that sum up to the target.

Longest Substring Without Repeating Characters

    Problem: Given a string, find the length of the longest substring without repeating characters.

    Algorithm: Sliding window approach.

Find the intersection of two arrays

    Problem: Given two arrays, find the common elements.

    Algorithm: Hashing, sorting.

Move zeros to the end of the array

    Problem: Given an array of integers, move all the zeros to the end while maintaining the relative order of the non-zero elements.
